# DJSwiftServer

A Vapor server for DJSwift station metadata, manifests, creator workflows, and the future hosted-radio API.

## Getting Started

To build the project using the Swift Package Manager, run the following command from `Server/`:

```bash
swift build
```

To run the project and start the server:

```bash
swift run
```

To execute tests:

```bash
swift test
```

The generated Fluent/Postgres Todo example is intentionally still present. It proves the Vapor CLI baseline, migration wiring, controller shape, and `VaporTesting` setup before DJSwift-specific station models replace it.
